## ⚙️ Deployment Setup

### 1. Create `.env` File

Create a `.env` file in your local project directory with your environment variables:

```bash
# MongoDB credentials
MONGO_USER=your_db_user
MONGO_PASSWORD=your_db_password
MONGO_DB_NAME=growlab

# Optional: backend settings
MONGO_HOST=localhost
MONGO_PORT=27017
```
